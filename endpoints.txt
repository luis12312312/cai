    <section class="block section-target" id="convenciones">
      <h2><span class="num">2</span>Convenciones y formato de respuesta</h2>
      <p class="lede">Todas las respuestas usan JSON UTF-8. Las fechas viajan en ISO-8601 UTC. Los errores siguen un formato unificado con un campo <code>code</code> estable (ideal para condicionales) y un <code>message</code> legible.</p>
      <h3 class="subhead">Codigos HTTP usados</h3>
      <div class="status-grid">
        <div class="status-card"><div class="code">200 OK</div><div class="desc">Operacion exitosa.</div></div>
        <div class="status-card"><div class="code">201 Created</div><div class="desc">Recurso creado.</div></div>
        <div class="status-card"><div class="code">400 Bad Request</div><div class="desc">Body o query invalidos.</div></div>
        <div class="status-card"><div class="code">401 Unauthorized</div><div class="desc">Token faltante / invalido / expirado.</div></div>
        <div class="status-card"><div class="code">403 Forbidden</div><div class="desc">Rol o estado insuficiente.</div></div>
        <div class="status-card"><div class="code">404 Not Found</div><div class="desc">Recurso no existe.</div></div>
        <div class="status-card"><div class="code">409 Conflict</div><div class="desc">Choque con datos existentes.</div></div>
        <div class="status-card"><div class="code">422 Unprocessable</div><div class="desc">Estado invalido para la operacion.</div></div>
        <div class="status-card"><div class="code">500 Internal Error</div><div class="desc">Error inesperado del backend.</div></div>
      </div>

    <!-- 4. AUTH -->
    <section class="block section-target" id="auth-jwt">
      <h2><span class="num">4</span>Autenticacion JWT y headers</h2>
      <p class="lede">El backend usa JWT Bearer. Todo endpoint protegido requiere el header <code>Authorization: Bearer &lt;accessToken&gt;</code>. El token vive 15 minutos (900s). No hay refresh token publico: cuando expire pedi credenciales nuevamente o re-login.</p>
      <h3 class="subhead">Claims dentro del JWT</h3>
      <table class="params">
        <tr><th>Claim</th><th>Tipo</th><th>Descripcion</th></tr>
        <tr><td class="field">sub</td><td class="type">uuid</td><td>userId del usuario.</td></tr>
        <tr><td class="field">role</td><td class="type">Role</td><td>Rol al momento de emitir el token.</td></tr>
        <tr><td class="field">activationState</td><td class="type">PENDING|ACTIVE</td><td>Estado al momento de emitir el token.</td></tr>
      </table>
      <div class="note"><span class="ico">!</span><div>Si el rol/estado del usuario cambia (por ejemplo se activa), el token anterior <b>no refleja el cambio</b>. Llama <code>/auth/me</code> y, si cambio, pedi un nuevo login para refrescar los claims.</div></div>
      <h3 class="subhead">Headers</h3>
      <div class="codewrap"><span class="label">JSON</span><button class="copy" onclick="copyEl(this)">Copiar</button>
<pre class="with-label">Content-Type: application/json
Accept: application/json
Authorization: Bearer &lt;accessToken&gt;</pre></div>
      <div class="codewrap"><span class="label">UPLOAD</span><button class="copy" onclick="copyEl(this)">Copiar</button>
<pre class="with-label">// multipart/form-data: NO setear Content-Type a mano,
// fetch() lo agrega solo con el boundary correcto cuando body = FormData.
Authorization: Bearer &lt;accessToken&gt;</pre></div>
    </section>

// scrollspy
const links = [...document.querySelectorAll('nav.sections a')];
const sections = [...document.querySelectorAll('section.block')];
function onScroll(){
  const y = window.scrollY + 80;
  let active = null;
  for(const s of sections){
    if(s.offsetTop <= y) active = s.id;
  }
  links.forEach(l=>l.classList.toggle('active', l.dataset.id === active));
}
window.addEventListener('scroll', onScroll, {passive:true});
window.addEventListener('load', onScroll);

// search filter
const search = document.getElementById('search');
search.addEventListener('input', () => {
  const q = search.value.trim().toLowerCase();
  sections.forEach(sec => {
    const text = sec.innerText.toLowerCase();
    sec.classList.toggle('hidden', q.length>1 && !text.includes(q));
  });
  links.forEach(l => {
    const text = l.innerText.toLowerCase();
    l.style.display = (q.length>1 && !text.includes(q)) ? 'none' : '';
  });
});
